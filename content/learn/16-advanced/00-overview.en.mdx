# Advanced: SMC, Volume Profile, Wyckoff, Elliott and Automation

After learning the basic tools, many people run after new frameworks: SMC this week, Elliott next week. Skill does not grow with the number of tools. This chapter looks at five popular advanced topics with **equal doubt and equal patience**.

## What are advanced frameworks

**These are separate languages for reading price, and behind each there is a model. The model may be useful, but it is not proven truth.**

This chapter answers one question: **"Which part of these advanced frameworks is useful for me, and how do I check it on my own data?"**

## Why learn this now

- **The base is built.** You have a [Plan](/en/learn/14-trading-plan-system/00-overview) and a [Backtest](/en/learn/15-backtesting-journal/00-overview), so you have the tools to check a new idea.
- **Understanding talk online.** Order block, POC, spring, wave 3: these words are everywhere.
- **Protection from false claims.** Learning to tell what is a model and what is a fact.
- **A filter before adding anything new.** Each tool must answer one specific question in your plan.

## What you will be able to do after this chapter

- **Look for an entry** by matching the **SMC sequence** (sweep → CHoCH → pullback).
- **Read the POC, VAH and VAL** of a **volume profile**.
- **Recognize the stages of Wyckoff accumulation.**
- **Work out an invalidation-based stop** from an **Elliott count**.
- **Arrange an out-of-sample test** before **automation**.

## How the lessons join together

A flow of analysis:

1. **Where is the market?** Inside or outside the value area (lesson 2).
2. **What is going on?** Accumulation, a trend or some other phase (lessons 3, 4).
3. **Where is the liquidity?** Whether the structure has changed after a sweep (lesson 1).
4. **Entry and stop?** Each framework gives its own invalidation level.
5. **Write it as rules and test.** Later in automation or the journal (lesson 5).

## How to read this chapter

- Learn one framework at a time and log 20 backtest trades, then the next.
- Do not put them all into the plan together. One tool for one question.
- Practice on demo first, and if the result does not match, that framework is not for you. That is an acceptable result.
- All charts in this chapter are imaginary (synthetic), to explain the idea. No claim here is anyone's real result.
