# Elliott Wave: গণনার নিয়ম, ব্যবহারযোগ্য অংশ ও সীমা

দশজন Elliott অনুসারীকে একই chart দেখালে বারোটি wave count পাবেন, এমন রসিকতা প্রচলিত। রসিকতাটিতে সত্য আছে: Elliott ব্যক্তিনির্ভর। তবু এতে একটি অংশ আছে যা সত্যিই কাজের: **স্পষ্ট invalidation level**। এই পাঠ সেটিকেই কেন্দ্র করে।

## এই লেখা পড়ে আপনি যা পারবেন

- **পাঁচ-wave impulse ও A-B-C correction** চিনতে পারবেন।
- **তিনটি অলঙ্ঘনীয় নিয়ম** দিয়ে count যাচাই করতে পারবেন।
- Count থেকে **stop ও target** বের করতে পারবেন।
- **ব্যক্তিনির্ভরতার সীমা** সৎভাবে মানতে পারবেন।

## কেন এটি জরুরি

- **বাজারের ঢেউ-গঠন নিয়ে জনপ্রিয় ভাষা।** অন্য trader-দের আলোচনা বোঝার জন্য শব্দগুলো জানা দরকার।
- **ঝুঁকির জন্য উপযোগী।** "এই দাম ভাঙলে count ভুল", এই স্পষ্টতা stop-কে যুক্তি দেয়।
- **[Fibonacci](/bn/learn/05-support-resistance/05-fibonacci-basics) ও [trend structure](/bn/learn/03-market-structure/02-trend-range-hhhl)-এর সঙ্গে সংযোগ।**

পূর্বশর্ত: [Wyckoff Basics](/bn/learn/16-advanced/03-wyckoff-basics) এবং [Swing High-Low](/bn/learn/03-market-structure/01-swing-high-low)।

## Elliott Wave কী

**Elliott Wave হলো এমন একটি তত্ত্ব, যা বলে প্রবণতা পাঁচটি wave-এ এগোয় (impulse) আর তিনটি wave-এ সংশোধিত হয় (A-B-C correction)।**

| Wave    | দিক                  | সংক্ষেপে                             |
| :------ | :------------------- | :----------------------------------- |
| 1, 3, 5 | প্রবণতার দিকে        | Impulse; 3 সাধারণত সবচেয়ে শক্তিশালী |
| 2, 4    | প্রবণতার বিপরীতে     | Correction                           |
| A, B, C | impulse-এর পর সংশোধন | A নিচে, B ওপরে, C নিচে               |

## তিনটি অলঙ্ঘনীয় নিয়ম (impulse-এর জন্য)

1. **Wave 2 কখনো wave 1-এর শুরুর বিন্দু ছাড়াবে না** (১০০%-এর বেশি ফিরবে না)।
2. **Wave 3 কখনো 1, 3, 5-এর মধ্যে সবচেয়ে ছোট হবে না।**
3. **Wave 4 কখনো wave 1-এর top-এর ভেতরে ঢুকবে না** (overlap নয়), সাধারণ impulse-এ।

কোনো নিয়ম ভাঙলে count ভুল। এটিই তত্ত্বের নিজস্ব "পরীক্ষা"।

## ধাপে ধাপে: count থেকে trade

<Steps>

### ধাপ ১: স্পষ্ট wave 1 খুঁজুন

পরিষ্কার একটি ধাক্কা। অস্পষ্ট হলে count করবেন না।

### ধাপ ২: Wave 2 দেখুন

তা wave 1-এর শুরু ছাড়াল কি না। ছাড়ালে count শেষ।

### ধাপ ৩: Entry ও stop

Wave 2-এর শেষ বা তার সংশোধনের পর। Stop wave 1-এর শুরুর **ঠিক নিচে**, কারণ সেটাই invalidation।

### ধাপ ৪: Target

ন্যূনতম 2R। Fibonacci projection (যেমন wave 1-এর দৈর্ঘ্যের গুণিতক) অতিরিক্ত নির্দেশক, নিশ্চয়তা নয়।

### ধাপ ৫: নিয়ম ভাঙলে তৎক্ষণাৎ বেরিয়ে যান

Wave 2 বা wave 4 নিয়ম ভাঙলে count বাতিল। "আরেকভাবে গুনি" বলে ধরে রাখবেন না।

</Steps>

## উদাহরণ ১: যখন কাজ করে (কাল্পনিক)

- **কী ছিল:** Wave 1: 1.0800 থেকে 1.0900। Wave 2 নেমে 1.0850 (50% ফেরত), শুরুর ওপরে।
- **চলাকালীন:** Buy 1.0853, stop 1.0795, target 1.0969 (2R)।
- **ফল:** Wave 3 উঠে 1.1010 পর্যন্ত গেছে, target ছুঁয়েছে, +2R। পরে wave 4, 5 এবং A-B-C গঠিত।
- **শিক্ষা:** Count থেকে পেলাম একটি স্পষ্ট stop। Count ঠিক হলে লাভ, ভুল হলে ক্ষতি সীমিত।

(কাল্পনিক শিক্ষামূলক উদাহরণ। এটি real trade নয়।)

## উদাহরণ ২: যখন ব্যর্থ হয় (কাল্পনিক)

- **কী ঘটল:** একই শুরু, buy 1.0853। কিন্তু দাম wave 1-এর শুরু ভেদ করে নেমে গেল।
- **ফল:** Stop 1.0795 লেগেছে, -1R।
- **কেন ব্যর্থ:** Wave 2 wave 1-এর ১০০%-এর বেশি ফিরেছে, অর্থাৎ নিয়ম-১ ভাঙা। Count মূলেই ভুল ছিল।
- **শিক্ষা:** Count ভুল হওয়া স্বাভাবিক। Stop ছিল বলে ক্ষতি 1R-এ আটকেছে। "আমি আবার গুনি" মানসিকতায় stop সরালে ক্ষতি বাড়ত।

(কাল্পনিক শিক্ষামূলক উদাহরণ। এটি real trade নয়।)

## সাধারণ ভুল

| ভুল                           | কেন হয়                   | কী করবেন                         |
| :---------------------------- | :------------------------ | :------------------------------- |
| পিছনে ফিরে সুন্দর count বসানো | Hindsight bias            | Live-এ অপেক্ষা করে count যাচাই   |
| নিয়ম ভাঙলেও count ধরে রাখা   | ধারণার প্রতি আসক্তি       | নিয়ম ভাঙা = বেরিয়ে যান         |
| একসঙ্গে একাধিক degree মেশানো  | সব ঢেউ দেখা               | একটি timeframe, একটি count       |
| Count-কে ভবিষ্যদ্বাণী ভাবা    | নিশ্চয়তার আকাঙ্ক্ষা      | Count = পরিকল্পনা, নিশ্চয়তা নয় |
| Stop ছাড়া Elliott            | "আমি তো জানি wave কোথায়" | Invalidation-এর ঠিক নিচে stop    |

  একটি বিকল্প count-ও লিখে রাখুন: "যদি এটি wave 2 না হয়, তবে কী?" দুই বিকল্প
  থাকলে একটিতে বিশ্বাস করে বসে থাকার ঝুঁকি কমে।
</Callout>

  কার্যকারিতার প্রমাণ নয়।

## কখন এটা কাজ করে না

- **Wave অস্পষ্ট হলে:** জোর করে count করলে সবই খাপ খায়।
- **ছোট timeframe-এ:** আওয়াজ বেশি, নিয়ম ভাঙা-মানা দুটোই যুক্তি দিয়ে সমর্থন করা যায়।
- **জটিল correction-এ:** Flat, zigzag, triangle, double three, এসব শ্রেণি শেখা আলাদা পরিশ্রম।
- **খবরের ধাক্কায়:** Count এক মুহূর্তে অচল।

## সারসংক্ষেপ

<KeyTakeaways>

- Impulse পাঁচ wave, correction তিন wave (A-B-C)।
- তিন নিয়ম: wave 2 শুরু ছাড়াবে না, wave 3 সবচেয়ে ছোট নয়, wave 4 wave 1-এ ঢুকবে না।
- Count-এর আসল কাজ: স্পষ্ট invalidation level ও stop।
- Count ব্যক্তিনির্ভর; নিয়ম ভাঙলে বেরিয়ে যান।

</KeyTakeaways>

## অনুশীলন

একটি পুরোনো D1 chart-এ একটি impulse চিহ্নিত করুন, তিনটি নিয়ম মিলিয়ে দেখুন। তারপর আরেকজনকে (বা নিজেকে এক সপ্তাহ পরে) একই chart দিয়ে count করতে বলুন। দুই count কতটা মেলে?

## কুইজ

1. Impulse-এ কয়টি wave, আর correction-এ কয়টি?
2. Wave 4 wave 1-এর top-এ ঢুকলে কী বোঝায়?
3. Count থেকে stop কোথায় বসে?
4. Elliott-এর সবচেয়ে বড় সীমা কী?

<details>
<summary>উত্তর দেখুন</summary>

**১.** Impulse-এ পাঁচটি, correction-এ তিনটি (A-B-C)।

**২.** সাধারণ impulse-এর নিয়ম ভাঙা, তাই count সম্ভবত ভুল।

**৩.** Wave 1-এর শুরুর ঠিক নিচে (invalidation)।

**৪.** ব্যক্তিনির্ভরতা: একই chart-এ ভিন্ন count সম্ভব।
